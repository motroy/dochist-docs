# dochist-docs

Public documentation and release-assets mirror for [`dochist`](https://github.com/motroy/dochist).

This repository is populated automatically by the `dochist` CI pipeline — nothing here is edited by hand:

- **Docs** (this README, LICENSE, `demo/`) are synced from `dochist`'s `main` branch and published as a static site via GitHub Pages.
- **Release assets** (cross-platform binaries + checksums) are published to this repo's [Releases](../../releases) page whenever a version tag is built in `dochist`.

Source code, issues, and pull requests live in the main repository: https://github.com/motroy/dochist
